## New Features

- 🌍 **Editor menus in your language** — The slash menu and the empty-line placeholder in the editor now follow your app language instead of staying in English.

## Improvements

- ✍️ **Shortcuts on selected blocks** — Bold, italic and other formatting shortcuts now work when you select whole blocks.
- 📂 **Enter on collapsed headings** — Pressing Enter at the end of a collapsed heading adds the new line after the hidden section, not inside it.
- 💡 **Callout submenu stays close** — The callout type submenu in the slash menu opens next to the main menu, and arrow keys move through it predictably.
- 🏷️ **Status defaults on new notes** — Notes created from a Type now get that Type's default Status (thanks @cadolphs).
- 🤖 **Hermes connects again** — The Hermes AI agent works with recent Hermes versions.
- ⚙️ **Tidier Settings** — Translated labels no longer overflow the Settings window, and the vault info tooltip shows above the window instead of behind it.

## Stability and Fixes

- Tolaria no longer freezes at launch with 100% CPU after updating, which affected some users on 2026-10-26.
- The window no longer goes white with an out-of-memory crash while an AI agent task is streaming.
- The standalone MCP server installs cleanly from its npm lockfile again.
- Plenty of under-the-hood cleanup, test, and release-pipeline work to keep Tolaria fast and reliable.
