## Improvements

- 🇷🇺 **Clearer Russian translations** — A few leftover English labels in the Russian localization, including Name and Diff, are now translated.

## Stability and Fixes

- Pasting formatted text into a quote block now stays inside the quote.
- Pasting markdown-style emphasis in the editor is more reliable on macOS.
- Undo after pasting a filename works as expected again.
- Clicking into a fenced code block now places the cursor inside the block.
- The Commit & Push dialog keeps its contents inside the window, even with a long author email.
- Windows WSL Git paths are shown in a readable form instead of the raw `\\?\` prefix.
