## Improvements

- ⚡ **Smoother AI panel** — Long AI answers stream in more smoothly, and the editor stays responsive while a response is still coming in.
- 🔍 **Cleaner quick open** — The line under the quick open search box is now a quiet grey instead of a bright blue.

## Stability and Fixes

- An empty `date` property that comes from a Type's defaults now opens the date picker instead of a plain text field.
- Properties whose names only happen to contain "date" or "end", like `sender`, `backend` or `candidate`, stay plain text instead of opening a date picker.
- Plenty of under-the-hood test and tooling work to keep Tolaria fast and reliable.
